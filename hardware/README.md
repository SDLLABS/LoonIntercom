# Hardware

Everything physical: the brass front, the box in the wall, the diffuser and dimensioned drawings
of the bought parts. All models are generated by scripts, so dimensions live in code, not in
hand-edited meshes.

## Folders

| Folder | What |
|---|---|
| [`front-sheet/`](front-sheet/) | `make_layout_v5.py` draws the front at true scale (1 unit = 1 mm): a dimensioned SVG, a reference PNG and a detail of the fold. The SVG also carries the engraving, which the CAD reads. |
| [`cad/`](cad/) | FreeCAD scripts. `kasten_v3_params.py` is the single source of dimensions for box and front; `make_kasten_v3.py` builds the box and carrier plate, `make_diffusor_v1.py` the diffuser, `make_sheet_v5.py` the front sheet. |
| [`models/`](models/) | Exported STL (for printing) and STEP (for CAD and metal shops). |
| [`parts/`](parts/) | Dimensioned drawings of bought parts, from datasheets and community measurements, and our own caliper measurements where makers publish nothing ([LilyGO display](parts/lilygo-t5-s3-touch-measured.md)). |

## Models

| File | Part | Print notes |
|---|---|---|
| `models/front-sheet-v5.step` | brass front, master | send this to a metal shop (2 mm brass, laser-cut, folded) |
| `models/front-sheet-v5_print.stl` | front, one piece, back on the bed | needs a bed diagonal of about 260 mm |
| `models/front-sheet-v5_print_front.stl` + `_roof.stl` | front split in two, with a lap joint and pegs | both fit side by side on a 256 × 256 bed |
| `models/box-v3_print.stl` | box that sits in the facade | ASA |
| `models/carrier-plate-v3_print.stl` | plate the electronics mount on | ASA |
| `models/diffuser-v1.step`, `diffuser-v1_print.stl` | quarter-round light diffuser | translucent filament |
| `models/diffuser-test-plate.stl` | test plate for the diffuser fit | |

The CAD comments are in German, as the project was designed in German.

## The engraving is a placeholder

The public front carries **MAX · ERIKA · ANNA · PAUL / MUSTERMANN**. To engrave your own names:

1. Edit `NAMES` and `FAMILY` at the top of `front-sheet/make_layout_v5.py`. Longer surnames are set
   smaller rather than squeezed.
2. Run it (needs Python with Pillow and fontTools; it uses the Segoe UI font that ships with
   Windows, which is **not** included here):
   ```
   python front-sheet/make_layout_v5.py
   ```
3. Rebuild the sheet with FreeCAD's command-line interpreter:
   ```
   cd cad
   freecadcmd build_front_sheet.py
   ```
   The results land in `cad/out/`.

## Measure before you commit

Several parts have dimensions nobody publishes (mounting holes of the display board, the
WT32-ETH01, module heights). The drawings in `parts/` mark them. The box design is on its
third iteration and will change once the real parts are measured.
